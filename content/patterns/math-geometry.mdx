## Intuition

These problems don't share one algorithm. They share a habit: before writing loops, look for the **property** that makes the problem simple. A rotation is two easy flips. A power can be built by squaring. A sequence of numbers that never reaches 1 must be stuck in a cycle.

Think of folding paper: rotating a sheet 90° is the same as flipping it along the diagonal and then left-to-right. You don't move each corner by hand — you compose two simple moves.

Shapes in this ladder:

- **Matrix index tricks**: rotate = transpose + reverse each row; spiral = four shrinking boundaries; Set Matrix Zeroes = use the first row and column as markers.
- **Digit-by-digit arithmetic**: carry from the right (Plus One), or multiply digits into position `i + j` (Multiply Strings) — exactly what you'd do on paper.
- **Exponentiation by squaring**: `x¹³ = x⁸ · x⁴ · x¹`, read off the bits of the exponent (Pow(x, n)).
- **Cycle detection on numbers**: apply a function repeatedly and use fast/slow pointers (Happy Number), like Linked List Cycle.

## Template

```python
def rotate(matrix: list[list[int]]) -> None:
    """Rotate an n×n matrix 90° clockwise, in place."""
    n = len(matrix)
    for i in range(n):
        for j in range(i + 1, n):
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]   # transpose
    for row in matrix:
        row.reverse()


def spiral(matrix: list[list[int]]) -> list[int]:
    out = []
    top, bottom, left, right = 0, len(matrix) - 1, 0, len(matrix[0]) - 1
    while top <= bottom and left <= right:
        for c in range(left, right + 1):
            out.append(matrix[top][c])
        top += 1
        for r in range(top, bottom + 1):
            out.append(matrix[r][right])
        right -= 1
        if top <= bottom:                        # a single row may already be used up
            for c in range(right, left - 1, -1):
                out.append(matrix[bottom][c])
            bottom -= 1
        if left <= right:                        # likewise a single column
            for r in range(bottom, top - 1, -1):
                out.append(matrix[r][left])
            left += 1
    return out


def my_pow(x: float, n: int) -> float:
    """Exponentiation by squaring: O(log n) multiplications."""
    if n < 0:
        x, n = 1 / x, -n
    result = 1.0
    while n:
        if n & 1:                                # this bit of the exponent is set
            result *= x
        x *= x
        n >>= 1
    return result


def is_happy(n: int) -> bool:
    def nxt(k: int) -> int:
        return sum(int(d) ** 2 for d in str(k))

    slow, fast = n, nxt(n)                       # Floyd's cycle detection
    while fast != 1 and slow != fast:
        slow, fast = nxt(slow), nxt(nxt(fast))
    return fast == 1
```

## Complexity

- Rotate, spiral, Set Matrix Zeroes: **O(m · n)** time, **O(1)** extra space for the in-place versions.
- Pow(x, n): **O(log n)** multiplications instead of O(n).
- Happy Number: each step shrinks large numbers quickly, so the cycle check finishes in a small number of steps.
- Multiply Strings: **O(m · n)** digit multiplications.

## Pitfalls

- Rotating by moving each element to its final spot in one pass without a temporary — you overwrite values you still need. Transpose + reverse avoids that.
- Spiral without the `top <= bottom` / `left <= right` checks repeats elements on non-square matrices.
- Set Matrix Zeroes: zeroing cells while still scanning, so new zeros trigger more zeros. Mark first, then clear — and remember separately whether row 0 and column 0 themselves contained a zero.
- Pow with a negative exponent: invert `x` and negate `n` first.
- Multiply Strings: converting to `int` defeats the point — build the result digit by digit into an array of length `m + n`.

## Tips & tricks

- Counter-clockwise rotation is transpose + reverse each **column** (or reverse the rows first, then transpose).
- Plus One: walk from the last digit; turn 9s into 0s until you find a digit below 9. If every digit was 9, prepend a 1.
- Multiply Strings: the product of `num1[i]` and `num2[j]` lands at positions `i + j` and `i + j + 1` of the result.
- Happy Number can use a `seen` set instead of fast/slow pointers — simpler, but O(cycle length) space.
- Many "math" problems are really one of the earlier patterns in disguise: cycle detection is **Linked List**, digit sums are **Arrays & Hashing**, and power-of-two checks are **Bit Manipulation**.
