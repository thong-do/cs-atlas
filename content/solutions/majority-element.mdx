## Intuition

Picture everyone in a room holding a card with their value. Two people whose cards differ pair off and leave together, again and again, until everyone still standing holds the same value. Each pair that leaves takes at most one majority card, always with a different card beside it. The majority holds more cards than everyone else combined, so the other cards run out first and a majority card is left standing. That relies on a majority existing: with cards 1, 2, 3, someone is left standing too, but not a majority.

## Brute force

For each value, count how often it appears in the whole list, and return the first one that appears more than half the time.

1. Let `n` be the length of `nums`.
2. For each value `x`, count how many times it appears in `nums`.
3. Return `x` as soon as that count is more than half of `n`.

```python
class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        n = len(nums)
        for x in nums:
            if nums.count(x) > n // 2:
                return x
```

Trace for `nums = [3, 3, 1, 1, 1]`, so `n // 2 = 2`:

| x | nums.count(x) | more than 2? |
|---|---|---|
| 3 | 2 | no |
| 3 | 2 | no |
| 1 | 3 | yes, return 1 |

**Complexity:** O(n²) time: each `nums.count(x)` scans all n values, and when the majority sits at the end, about n/2 values are checked before it. O(1) extra space.

**What's wasted:** every check rescans the whole list, even for a value that was already counted (the second 3 above). One pass that keeps a running tally per value counts everything once.

## Better

Keep a tally per value in a map during one pass, and return the value whose tally passes half.

1. Start with an empty map, `counts`, from value to tally.
2. For each value `x`, add one to `counts[x]`.
3. Return `x` as soon as its tally is more than half the list's length.

```python
class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        counts = {}
        for x in nums:
            counts[x] = counts.get(x, 0) + 1
            if counts[x] > len(nums) // 2:
                return x
```

Trace for `nums = [3, 3, 1, 1, 1]`:

| x | counts afterwards | counts[x] more than 2? |
|---|---|---|
| 3 | `{3: 1}` | no |
| 3 | `{3: 2}` | no |
| 1 | `{3: 2, 1: 1}` | no |
| 1 | `{3: 2, 1: 2}` | no |
| 1 | `{3: 2, 1: 3}` | yes, return 1 |

**Complexity:** O(n) time on average: one map update per value. O(n) extra space, because `counts` keeps one key per distinct value, which can be about n/2 keys.

**What's wasted:** the map keeps a tally for every distinct value, yet only one value can hold more than half. The pairing-off picture needs just one candidate and one number.

## Optimal

Walk the list keeping a `candidate` and its number of unpaired supporters, `votes`; each different value cancels one supporter (Boyer–Moore voting).

1. Start with no `candidate` and zero `votes`: nobody is standing.
2. For each value `x`, if `votes` is 0, `x` becomes the `candidate`.
3. If `x` equals `candidate`, add one vote; otherwise `x` pairs off with a supporter: subtract one.
4. Return `candidate`: because a majority is guaranteed, it is the value left standing.

```python
class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        candidate, votes = None, 0
        for x in nums:
            if votes == 0:
                candidate = x         # nobody is standing, so x steps up
            if x == candidate:
                votes += 1            # one more supporter standing
            else:
                votes -= 1            # x and one supporter pair off and leave
        return candidate
```

Trace for `nums = [3, 3, 1, 1, 1]`:

| x | candidate | votes |
|---|---|---|
| 3 | 3 | 1 |
| 3 | 3 | 2 |
| 1 | 3 | 1 |
| 1 | 3 | 0 |
| 1 | 1 | 1 |

The 3s lead early, but each 1 pairs off with a 3, and the last 1 is left standing: the answer is 1. Without a guaranteed majority, the final `candidate` could be wrong (for `[1, 2, 3]` it is 3), and a second pass would have to count it.

**Complexity:** O(n) time, one pass. O(1) extra space: just `candidate` and `votes`.
