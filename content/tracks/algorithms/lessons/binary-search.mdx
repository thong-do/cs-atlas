## Intuition

Whenever you can ask a yes/no question whose answers look like `False … False True … True` across the search space, you can find the boundary in O(log n) by checking the middle and discarding half.

It's the "guess my number from 1 to 100, higher or lower?" game: seven guesses are always enough.

Sorted arrays are the obvious case. The bigger idea is **binary search on the answer**: "Can Koko finish at speed k?" — if speed k works, every faster speed works too, so search for the smallest k that works.

## Template

```python
def first_true(lo: int, hi: int, ok) -> int:
    """Smallest x in [lo, hi] with ok(x) True; ok must look like F..F T..T.
    Returns hi + 1 when no x works."""
    hi += 1
    while lo < hi:
        mid = (lo + hi) // 2
        if ok(mid):
            hi = mid
        else:
            lo = mid + 1
    return lo


def search(nums: list[int], target: int) -> int:
    i = first_true(0, len(nums) - 1, lambda m: nums[m] >= target)   # lower bound
    return i if i < len(nums) and nums[i] == target else -1


def min_eating_speed(piles: list[int], h: int) -> int:              # search on the answer
    return first_true(1, max(piles), lambda k: sum((p + k - 1) // k for p in piles) <= h)
```

## Complexity

- Time: **O(log n)** for an array search; **O(log(range) × cost of ok)** when searching on the answer.
- Space: **O(1)**.

## Pitfalls

- Infinite loops from `lo = mid` when `mid = (lo + hi) // 2` — the range can stop shrinking.
- Mixing inclusive and exclusive bounds in the same loop. Pick one convention (the template uses `[lo, hi)`).
- Searching on a condition that isn't monotonic — binary search silently returns garbage.
- Rotated arrays: compare `nums[mid]` with `nums[hi]` (not `nums[lo]`) to find the minimum.

## Tips & tricks

- Write the `ok(x)` predicate first, then the bounds; the loop is always the same.
- "Minimum x such that …" or "maximum x such that …" is the signal for searching on the answer.
- Python's `bisect.bisect_left` is the lower bound.
- A row-major sorted matrix is a 1-D array: index `i` ↔ `(i // cols, i % cols)`.
